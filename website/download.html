  1. If Chrome says the file isn't commonly downloaded, open the download list and choose Keep. New apps show this until enough people have downloaded them.
  2. Run SwarmCode-Setup from your downloads.
  3. If Windows SmartScreen appears, click More info, then Run anyway. Early builds aren't code-signed yet.
  4. Open SwarmCode, sign in, and add a model: an API key, or a free local model with Ollama.
  5. Prefer the terminal? npm i -g swarmcode, then swarm.
